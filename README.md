🌐 **[diegoosd7.github.io/Portfolio](https://diegoosd7.github.io/Portfolio/)**

**ES** · Mi portfolio personal: experiencia, educación, habilidades y proyectos. Disponible en español e inglés, con modo claro y oscuro.

**EN** · My personal portfolio: experience, education, skills and projects. Available in Spanish and English, with light and dark mode.

## Tecnologías / Tech stack

React · Vite · Tailwind CSS · Font Awesome · Devicon · GitHub Pages

## Ejecutar en local / Run locally

```bash
git clone https://github.com/Diegoosd7/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Abre / Open `http://localhost:5173/Portfolio/`
